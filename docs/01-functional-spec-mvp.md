# 게임 파티 자동 매칭 서비스 기능 명세서 — MVP

## 문서 범위

- 이 문서는 최초 출시 단계에서 구현할 기능만 정의한다.
- 서비스 대상은 국내 이용자이며 모든 일정은 한국 표준시를 기준으로 한다.
- 대상 게임군은 리그 오브 레전드, PUBG, Steam 멀티플레이 게임이다.
- 서비스 자체 회원가입과 비밀번호 로그인을 제공하지 않는다.
- 일치도 점수, 조건 자동 완화, 반복 예약, 평가·차단·신고, 과거 이용 내역과 운영자 화면은 포함하지 않는다.

## 1. 서비스 접속과 기본 정보

### 1.1 로그인 없는 바로 시작

- 회원가입·로그인 화면 없이 서비스에 바로 접속한다.
- 첫 접속 시 브라우저에 익명 이용자 식별자를 발급한다.
- 같은 브라우저에서는 진행 중인 매칭 요청과 확정 파티 상태를 다시 확인할 수 있다.
- 쿠키를 삭제하거나 다른 기기를 사용하면 기존 상태를 복구할 수 없다는 점을 안내한다.

### 1.2 국내 서비스 고정

- 국가·지역 선택 기능을 제공하지 않는다.
- 언어 설정과 언어 기반 매칭을 제공하지 않는다.
- 롤은 한국 서버를 기준으로 한다.
- 예약 시간은 모두 한국 표준시로 표시한다.

### 1.3 기본 프로필

- 서비스에서 사용할 닉네임을 설정한다.
- 음성채팅 조건을 `필수`, `가능`, `사용하지 않음` 중에서 선택한다.
- 마이크 사용 가능 여부를 설정한다.
- 플레이 목적을 선택한다.
  - 가볍게 즐기기
  - 승리·랭크 상승
  - 초보자 학습
  - 숙련자 중심 플레이
  - 스토리 진행
  - 업적 달성
  - 파밍·반복 플레이
  - 장시간 세션
- 플레이 분위기를 `편안함`, `적당한 집중`, `높은 집중도` 중에서 선택한다.

## 2. 게임 계정과 인게임 정보 연동

### 2.1 공통 기능

- 게임별 계정 정보를 한 번 등록한다.
- 연결 상태를 `정상`, `확인 필요`, `정보 비공개`, `조회 실패`로 표시한다.
- 마지막 정보 갱신 시각을 표시한다.
- 매칭 신청 시 정보가 오래됐으면 자동으로 다시 조회한다.
- 사용자가 직접 `새로고침`을 눌러 갱신할 수 있다.
- 매칭에 필요한 요약 정보만 다른 참가자에게 공개한다.

### 2.2 리그 오브 레전드

- `게임 이름#태그` 형식의 Riot ID를 입력한다.
- 한국 서버의 계정을 조회한다.
- Riot 공식 API를 통해 다음 정보를 자동으로 가져온다.
  - 솔로 랭크 티어·단계·LP
  - 자유 랭크 티어·단계·LP
  - 승·패
  - 배치 진행 또는 언랭크 여부
- 솔로 랭크와 자유 랭크를 구분해 표시한다.
- 매칭에 사용할 큐를 선택한다.
- 주 포지션과 부 포지션을 선택한다.
  - 탑
  - 정글
  - 미드
  - 바텀
  - 서포터
  - 상관없음
- MVP의 Riot ID 입력 방식은 계정 소유자를 검증하지 못한다는 점을 표시한다.

### 2.3 PUBG

- 플레이 플랫폼과 인게임 닉네임을 입력한다.
- MVP에서 지원하는 플랫폼만 선택지에 표시한다.
- PUBG 공식 API를 통해 다음 정보를 자동으로 가져온다.
  - 현재 시즌 티어·서브티어 또는 랭크 포인트
  - 플레이 수
  - 승리·상위권 기록
  - 매칭에 사용하기로 정한 기본 전적
- 일반전과 경쟁전을 구분한다.
- 솔로·듀오·스쿼드를 구분한다.
- FPP·TPP를 구분한다.
- 경쟁전 기록이 없는 사용자는 정상적인 `언랭크` 상태로 처리한다.

### 2.4 Steam

- `Steam 연결` 버튼을 통해 SteamID를 연결한다.
- 서비스가 Steam 비밀번호를 직접 입력받지 않는다.
- 지원 게임 중 사용자가 보유한 게임을 자동으로 표시한다.
- 지원 게임별 누적 플레이시간을 가져온다.
- 게임 정보가 비공개이면 조회할 수 없다는 안내와 공개 설정 방법을 보여준다.
- 비공개 상태에서는 게임별 정책에 따라 `초보`, `경험 있음`, `숙련`을 수동 선택할 수 있다.
- 수동 입력 정보에는 `미검증` 표시를 붙인다.

### 2.5 Discord

- 사용자가 최초 한 번 Discord 계정을 연결한다.
- 서비스 Discord 서버 가입에 필요한 권한을 승인받는다.
- 음성채팅 필수 매칭은 Discord 연결이 완료되어야 신청할 수 있다.
- 연결된 Discord 계정과 연결 상태를 표시한다.

## 3. 지원 게임 탐색

### 3.1 게임 목록

- 지원 중인 롤, PUBG, Steam 게임을 한 화면에 보여준다.
- 게임 카드에 다음 정보를 표시한다.
  - 게임명과 대표 이미지
  - 지원 플랫폼
  - 기본 파티 인원
- 게임명으로 검색한다.
- 한글명과 영문명을 모두 검색 대상으로 사용한다.
- 협동, 경쟁, 전략, 생존, 파티게임 등의 분류를 제공한다.

## 4. 매칭 요청 생성

### 4.1 즉시 매칭

- `지금 바로 플레이`를 선택한다.
- 최대 대기시간을 선택한다.
- 대기 시작 후 현재 상태와 경과 시간을 보여준다.

### 4.2 일회성 예약 매칭

- 원하는 날짜와 시작 시각을 선택한다.
- 오늘 날짜의 예약은 신청할 수 없으며 다음 날 이후만 선택한다.
- 당일 예약 신청은 플레이 전날 23시 59분에 마감한다.
- 예상 플레이시간을 설정한다.
- 시작 가능 범위를 선택한다.
  - 정확한 시각
  - 앞뒤 30분 가능
  - 앞뒤 1시간 가능
- 예약 매칭은 플레이 당일 00시에 실행되며 성립한 파티는 별도의 수락 없이 자동 확정된다는 점을 신청 전에 안내한다.

### 4.3 게임과 인원 선택

- 한 요청에는 게임 하나만 선택한다.
- 게임별 허용 범위 안에서 목표 파티 인원을 선택한다.
- 혼자 신청하는 방식만 지원한다.
- 친구와 함께 신청하는 기존 파티 기능은 제공하지 않는다.

### 4.4 게임별 매칭 조건

- 사용자가 선택한 조건은 모두 반드시 맞아야 하는 조건으로 처리한다.
- `필수 조건`과 `선호 조건`을 구분하지 않는다.
- 롤 조건
  - 솔로·자유·일반 등 게임 모드
  - 허용 티어 범위
  - 주·부 포지션
  - 음성채팅 여부
  - 플레이 목적
- PUBG 조건
  - 일반전·경쟁전
  - 솔로·듀오·스쿼드
  - FPP·TPP
  - 허용 랭크 범위
  - 음성채팅 여부
  - 플레이 성향
- Steam 게임 조건
  - 게임 보유 여부
  - 플레이시간 또는 숙련 구간
  - 플레이 목적
  - 난이도
  - 음성채팅 여부
  - 게임별로 반드시 필요한 추가 조건

### 4.5 신청 확인과 수정

- 신청 전 게임, 일정, 인원과 모든 조건을 한 화면에 요약한다.
- Discord 연결이 필요한 요청은 연결 상태를 확인한다.
- 즉시 매칭 요청은 매칭 제안이 생성되기 전까지 수정하거나 취소할 수 있다.
- 일회성 예약 요청은 플레이 전날 23시 59분까지 수정하거나 취소할 수 있다.

## 5. 자동 매칭

### 5.1 후보 제외

- 게임과 게임 모드가 다르면 제외한다.
- 플레이 가능한 시간이 겹치지 않으면 제외한다.
- 목표 파티 인원을 구성할 수 없으면 제외한다.
- 음성채팅 조건이 다르면 제외한다.
- 게임별 필수 조건이 다르면 제외한다.
- 이미 다른 확정 파티와 일정이 겹치면 제외한다.

### 5.2 후보 처리 순서

- 모든 조건을 통과한 사람만 후보가 된다.
- 후보 중 먼저 신청한 이용자를 우선한다.
- 별도의 유사도·신뢰도 점수를 계산하지 않는다.
- 대기시간에 따라 조건을 자동으로 완화하지 않는다.
- 조건이 너무 좁으면 사용자가 요청을 직접 수정해야 한다.

### 5.3 파티 구성

- 게임별 목표 인원을 채울 수 있는 후보를 묶는다.
- 동시에 여러 매칭이 실행돼도 한 사람이 두 파티에 들어가지 않게 한다.
- 하나의 요청은 동시에 하나의 파티 구성에만 포함한다.

## 6. 즉시 매칭 제안과 수락

### 6.1 제안 도착

- 즉시 매칭에서 후보 파티가 만들어지면 참가자 전원에게 동시에 제안을 보낸다.
- 게임, 시작 시각, 인원과 일치한 조건을 보여준다.
- 상대방의 직접 연락처는 확정 전까지 공개하지 않는다.
- 남은 수락 시간을 실시간으로 표시한다.

### 6.2 수락·거절

- 사용자는 제안을 수락하거나 거절한다.
- 수락 후 다른 참가자의 응답 현황을 익명으로 보여준다.
- 제한시간까지 응답하지 않으면 자동 거절로 처리한다.
- 중복 클릭이나 네트워크 재전송에도 같은 요청을 한 번만 처리한다.
- 거절한 사람이 누구인지는 다른 참가자에게 공개하지 않는다.

### 6.3 확정과 재매칭

- 즉시 매칭은 필요한 인원이 전부 수락했을 때만 파티를 확정한다.
- 한 명이라도 거절하거나 시간초과되면 해당 제안을 종료한다.
- 이미 수락했던 정상 이용자는 기존 대기 순서를 유지한 채 다시 대기한다.
- 실패한 동일 조합을 바로 다시 제안하지 않는다.
- 사용자는 `계속 찾기` 또는 `매칭 종료`를 선택한다.

## 7. 진행 중 요청과 예약 관리

### 7.1 현재 요청 확인

- 현재 브라우저에서 진행 중인 요청만 보여준다.
- 다음 상태를 표시한다.
  - 예약됨
  - 매칭 대기 중
  - 후보 구성 중
  - 수락 대기 중
  - 매칭 확정
  - 재매칭 중
  - 취소됨
  - 매칭 실패
  - 완료됨
- 과거에 완료된 파티 목록은 제공하지 않는다.

## 8. 확정 파티 관리

### 8.1 파티 상세

- 게임, 시작·종료 예정 시각, 참가 인원과 합의된 조건을 표시한다.
- 참가자의 서비스 닉네임과 필요한 인게임 요약 정보를 보여준다.
- 확정 이후에만 Riot ID, PUBG 닉네임, Steam 프로필 등 합류에 필요한 정보를 공개한다.
- Discord 방 입장 버튼을 제공한다.

### 8.2 준비 확인

- 시작 전에 `참여 가능`, `늦을 예정`, `참여 불가` 중 하나를 선택한다.
- 아직 응답하지 않은 인원 수를 보여준다.
- 취소자가 발생해도 빈자리를 자동 충원하지 않는다.

### 8.3 확정 후 취소

- 확정된 파티에서 나갈 수 있다.
- 취소 사유와 시각을 기록한다.
- 시작 직전 취소에는 경고를 보여준다.
- 필요한 최소 인원을 채우지 못하면 파티 전체를 취소하고 참가자에게 알린다.

### 8.4 완료 처리

- 예정 종료 시각이 지나면 파티를 완료 상태로 전환한다.
- 파티원 평가나 신고를 요청하지 않는다.

## 9. Discord 파티방

### 9.1 전용방 자동 생성

- 매칭 확정 시 Discord Bot이 전용 텍스트 공간과 음성 채널을 생성한다.
- 방 이름은 게임명과 파티 번호를 사용한다.
- 참가자에게 임시 역할 또는 사용자별 접근 권한을 부여한다.
- 매칭되지 않은 사람은 전용방을 볼 수 없다.

### 9.2 한 번 클릭 입장

- 파티 상세에 `Discord 방 입장` 버튼을 표시한다.
- 버튼을 누르면 Discord 앱 또는 웹의 해당 채널로 이동한다.
- 접속하지 않은 사용자를 음성 채널에 강제로 입장시키지는 않는다.

### 9.3 생성 실패와 정리

- 방 생성 실패 시 자동으로 재시도한다.
- 재시도 중임을 파티 화면에 표시한다.
- 계속 실패하면 공용 대기 채널 또는 임시 초대 링크를 제공한다.
- 플레이 종료 후 유예시간이 지나면 전용방과 임시 역할을 삭제한다.

## 10. 실시간 상태와 알림

### 10.1 인앱 실시간 상태

- 새로고침 없이 대기·제안·수락·확정 상태를 갱신한다.
- 연결이 끊기면 자동 재연결한다.
- 재연결 후 현재 상태를 다시 불러온다.

### 10.2 Web Push

- 브라우저가 닫혀 있어도 다음 내용을 알린다.
  - 즉시 매칭 제안 도착
  - 수락 제한시간 임박
  - 매칭 확정
  - 파티 취소
  - 시작 전 준비 확인
- 알림 권한을 거부한 사용자는 주요 알림을 놓칠 수 있음을 안내한다.

### 10.3 예약 리마인더

- 파티 시작 24시간 전, 1시간 전, 10분 전 등 정해진 시점에 알린다.
- 이미 취소된 파티에는 알림을 보내지 않는다.

## 11. 예외 처리

### 11.1 외부 게임 정보 오류

- Riot ID 형식 오류, 존재하지 않는 계정, 언랭크와 API 장애를 구분한다.
- PUBG 플레이어 없음, 플랫폼 불일치, 시즌 기록 없음과 API 장애를 구분한다.
- Steam 프로필 비공개, 게임 미보유와 API 장애를 구분한다.
- Discord 권한 거절, 서버 가입 실패와 방 입장 권한 실패를 구분한다.
- 기존 조회 정보가 있으면 마지막 갱신 시각을 함께 표시한다.

### 11.2 매칭 오류

- 시간이 겹치는 요청을 중복 생성하지 못하게 한다.
- 여러 사용자가 동시에 응답해도 파티 정원을 초과하지 않게 한다.
- 만료된 제안에 응답하면 최신 상태를 다시 보여준다.
- 브라우저를 닫았다가 다시 열면 현재 진행 상태를 복구한다.

### 11.3 시간 오류

- 이미 지난 시각으로 예약하지 못하게 한다.
- 오늘 날짜의 일회성 예약은 신청하지 못하게 한다.
- 플레이 전날 23시 59분이 지난 예약은 새로 만들거나 수정하지 못하게 한다.

## 12. 자동 처리

### 12.1 일회성 예약 매칭 배치

- 매일 00시 한국 표준시를 기준으로 당일 일회성 예약 매칭을 한 번 실행한다.
- 당일 예약은 전날 23시 59분까지 신청할 수 있다.
- 00시 이후에는 당일 예약을 새로 신청할 수 없으며 즉시 매칭을 이용해야 한다.
- 당일 대기 중인 일회성 예약만 조회한다.
- 예약을 게임별로 나눈 뒤 플레이 가능 시간과 필수 조건이 일치하는 이용자로 파티를 구성한다.
- 매칭된 파티는 별도의 수락 절차 없이 자동 확정한다.
- 파티를 구성하지 못한 예약은 매칭 실패로 종료한다.
- 미래 날짜의 예약은 해당 플레이 날짜 00시가 될 때까지 처리하지 않는다.
- 작업 장애로 배치가 재실행되더라도 사용자가 여러 파티에 중복 배정되지 않게 한다.

### 12.2 즉시 매칭 만료

- 최대 대기시간이 지나면 즉시 매칭 요청을 자동 종료한다.
- 수락 제한시간이 지나면 해당 즉시 매칭 제안을 자동 거절 처리한다.

### 12.3 외부 정보 동기화

- Riot·PUBG·Steam 정보의 갱신 주기를 관리한다.
- 최신 정보는 다시 호출하지 않고 저장된 값을 사용한다.
- 동일 계정에 대한 동시 조회를 하나로 합친다.
- 외부 API 호출 제한과 일시 장애에 대응한다.

### 12.4 알림 작업

- 파티 확정 시 예약 리마인더 작업을 생성한다.
- 파티 취소 시 남은 알림 작업을 취소한다.
- 동일한 알림을 중복 발송하지 않는다.

### 12.5 Discord 작업

- 파티 확정 후 방을 생성한다.
- 실패한 생성을 제한된 횟수만 재시도한다.
- 파티 종료 후 방과 임시 역할을 삭제한다.
- 이미 정리된 방에 삭제 작업이 다시 실행돼도 오류 없이 끝낸다.

## 13. MVP 완료 기준

- [ ] 로그인 없이 즉시 이용할 수 있다.
- [ ] 롤·PUBG·Steam 게임 정보를 자동으로 가져올 수 있다.
- [ ] Discord 계정을 연결할 수 있다.
- [ ] 즉시 매칭과 일회성 예약을 만들 수 있다.
- [ ] 매일 00시에 당일 일회성 예약을 매칭하고 성립한 파티를 자동 확정할 수 있다.
- [ ] 게임별 조건이 일치하는 사람을 신청 순서대로 구성할 수 있다.
- [ ] 동시에 매칭해도 사용자가 중복 배정되지 않는다.
- [ ] 즉시 매칭 제안과 전원 수락을 처리할 수 있다.
- [ ] 실패한 즉시 매칭 제안의 정상 이용자를 재대기시킬 수 있다.
- [ ] 확정 파티와 준비 확인·취소 상태를 관리할 수 있다.
- [ ] 매칭 확정 후 Discord 전용방을 자동 생성할 수 있다.
- [ ] 인앱 상태와 Web Push 알림을 제공할 수 있다.
- [ ] 만료·알림·Discord 방을 자동 정리할 수 있다.
